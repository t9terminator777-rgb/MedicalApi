# MedicalApi — учебный Web API клиники на C#

Учебный ASP.NET Core Web API для управления пациентами, медицинскими справками, каталогом видов справок и записями на приём. Swagger UI используется для просмотра и ручной проверки запросов.

## Запуск

Требуется .NET 10 SDK.

```powershell
dotnet restore
dotnet run --urls http://localhost:5138
```

Откройте Swagger: <http://localhost:5138/swagger>.

## Возможности

- Пациенты: список, поиск по Id, создание, изменение, удаление.
- Справки: список, получение по Id, создание, изменение, удаление.
- Каталог видов справок: CRUD; изначально есть четыре вида с ценой и сроком действия.
- При создании справки сервер проверяет пациента и вид справки, а название и цену берёт из каталога.
- Справки можно фильтровать по пациенту или названию, а также сортировать по Id, цене и дате.
- Для карточки пациента есть адрес `/api/patients/{id}/spravki`.
- Дополнительный модуль записей к врачу: список, получение, создание, изменение, удаление.
- Проверяются обязательные поля, даты, цена, существование связанных пациента и вида справки.
- Удаление пациента удаляет также его справки и записи на приём; вид справки, уже использованный в справке, удалить нельзя.

## Примеры запросов

Создать пациента через `POST /api/patients`:

```json
{
  "name": "Алиса",
  "birthDate": "2000-05-15",
  "phone": "+996111222333",
  "email": "alice@example.com",
  "bloodType": "O+"
}
```

Создать справку через `POST /api/spravki` (название и стоимость не присылаются, они берутся из каталога):

```json
{
  "patientId": 1,
  "spravkaTypeId": 2
}
```

Отфильтровать и отсортировать справки:

```text
GET /api/spravki?patientId=1&sortBy=price&order=desc
GET /api/spravki?search=бассейн
```

Коды ответов: `200 OK` — успешное чтение/изменение, `201 Created` — создана запись, `204 No Content` — удалена запись, `400 Bad Request` — неверные данные или связь, `404 Not Found` — запись не найдена, `409 Conflict` — нельзя удалить используемый вид справки.

## Учебное ограничение

Данные хранятся в списках в памяти процесса. При перезапуске сервера пациенты, справки и записи создаются заново; постоянный каталог видов справок загружается из исходного кода. База данных в задании не подключалась.
